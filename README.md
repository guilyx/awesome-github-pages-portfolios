## Contributing

Contributions are always welcome! You only need to add **one small YAML file** — the README and the gallery update themselves.

1. **[Create your entry file](https://github.com/guilyx/awesome-github-pages-portfolios/new/master/data/portfolios?filename=your-name.yml&value=%23%20yaml-language-server%3A%20%24schema%3D..%2F..%2Fschema%2Fportfolio.schema.json%0Aname%3A%20Your%20Name%0Arepo%3A%20your-username%2Fyour-username.github.io%0Ademo%3A%20https%3A%2F%2Fyour-username.github.io%2F%0A%23%20Optional%3A%0A%23%20description%3A%20One%20line%20about%20your%20portfolio%20%2810-160%20characters%29.%0A%23%20tags%3A%20%5Breact%2C%20minimal%2C%20dark%5D%0A)** in `data/portfolios/` (GitHub forks the repo for you).
2. Fill in `name`, `repo` and `demo`, then open a pull request. CI checks your entry automatically.
3. Once merged, the list and the [gallery](https://guilyx.github.io/awesome-github-pages-portfolios/) are rebuilt and your site shows up with a screenshot. 🎉

Step-by-step tutorial: [CONTRIBUTING.md](CONTRIBUTING.md). Please also read the [Code of Conduct](CODE_OF_CONDUCT.md).
